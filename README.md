# SVG Downloadr

Chrome-расширение (Manifest V3): прокручивает открытую страницу до конца, собирает все
`<img>`, у которых `src` — SVG, и сохраняет выбранные картинки одним PDF.

Стек: Vue 3 + Vite, PDF собирается через jsPDF и svg2pdf.js. Все зависимости попадают
в бандл — расширение ничего не грузит из сети во время работы.

## Сборка

```bash
npm install && npm run build
```

Готовое расширение появится в `dist/`.

## Установка в Chrome

1. Открыть `chrome://extensions/`
2. Включить «Режим разработчика»
3. «Загрузить распакованное расширение» → выбрать папку `dist`

## Как пользоваться

1. Открыть нужный сайт, нажать на иконку расширения.
2. **Сканировать страницу** — расширение само прокрутит её сверху донизу, подхватывая
   картинки, которые подгружаются лениво, и вернёт прокрутку на исходное место.
3. Снять галочки с ненужных SVG.
4. **Скачать PDF** — каждая картинка ляжет на отдельную страницу.

Настройки внизу попапа:

| Настройка | Значения | Что делает |
|---|---|---|
| Страница | `A4, вписать` / `По размеру SVG` | Формат страницы PDF |
| Отрисовка | `Вектор` / `Растр` | Вектор масштабируется без потерь; растр повторяет картинку пиксель в пиксель |

## Языки

Интерфейс на русском и английском. Язык подставляется по языку Chrome, переключатель
`RU`/`EN` в правом верхнем углу попапа меняет его вручную — выбор запоминается.
Название и описание расширения в `chrome://extensions/` тоже локализованы
(через `_locales/`, штатный механизм Chrome).

Строки интерфейса лежат в [src/lib/i18n.js](src/lib/i18n.js), тексты манифеста —
в `public/_locales/<lang>/messages.json`. Чтобы добавить ещё язык, нужен новый блок
в `MESSAGES`, его код в `LOCALES` и одноимённая папка в `_locales/`.

## Что именно ищет сканер

`<img>`, у которых `src` (или `currentSrc`) заканчивается на `.svg`/`.svgz`, а также
`data:image/svg+xml`. Дубликаты по URL отбрасываются. Если у документа нет собственной
прокрутки, сканер находит самый крупный внутренний скролл-контейнер и прокручивает его.

## Ограничения

- Картинки внутри `<iframe>` не сканируются — только основной документ.
- В режиме «Вектор» свои шрифты в PDF не встраиваются: `font-family` сводится к базовым
  PDF-шрифтам (Helvetica / Times / Courier). Если важно точное начертание — выбирайте «Растр».
- SVG со ссылками на внешние ресурсы (растровые вставки, подключённые шрифты) рендерятся
  без них — так их изолированно отдаёт браузер.
- Если SVG не удалось перевести в вектор (сложные фильтры и маски), он автоматически
  вставляется растром, а в попапе появляется предупреждение.
- На `file://`-страницах нужно разрешить расширению доступ к файлам в `chrome://extensions/`.

## Структура

```
popup.html              точка входа попапа
src/popup/              UI на Vue (App.vue, SvgTile.vue, стили)
src/content.js          сканер страницы: прокрутка и сбор <img>
src/lib/scan.js         обвязка над chrome.* (инъекция, загрузка SVG, кэш скана)
src/lib/svg.js          разбор SVG, размеры, шрифты, растеризация
src/lib/pdf.js          сборка PDF
src/lib/i18n.js         переводы интерфейса и сообщений об ошибках
src/lib/errors.js       ошибки с кодами (текст подбирает попап)
public/manifest.json    манифест расширения
public/_locales/        локализация названия и описания расширения
```
